# 🛒 Fordo - Modern Grocery & E-commerce Platform

A scalable, full-stack grocery and e-commerce web application designed with a single-vendor foundation and built-in architecture for future multi-vendor and zone-based delivery scaling.

---

## 🚀 Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS, Redux Toolkit (RTK Query)
- **Backend:** Node.js, Express.js
- **Database & ORM:** PostgreSQL, Prisma ORM
- **Package Manager:** npm

---

## 📌 Features

- **User Roles & Authentication:**
  - `CUSTOMER`: Browse products, manage cart/wishlist, place orders.
  - `ADMIN`: Manage products, categories, stock, and view order analytics.
  - `MANAGER` & `DELIVERY_MAN`: Order processing and status tracking.
  - `VENDOR` *(Future Ready)*: Multi-vendor store management.
- **Product & Category Management:** Supports units (kg, gm, liter), discounts, and multiple images.
- **Cart & Order System:** Snapshot-based invoice calculation and live status tracking.
- **Address & Area Delivery:** Prepared for dynamic zone-based delivery fees.
